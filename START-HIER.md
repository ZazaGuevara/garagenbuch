# So startest du das Projekt in Claude Code (Mac)

1. Diese ZIP-Datei entpacken (Doppelklick) und den Ordner **garagenbuch-projekt** an einen festen Ort legen, z.B. in «Dokumente».
2. Die **Claude-App** auf dem Mac öffnen und anmelden, dann oben auf den Tab **«Code»**.
3. Den Ordner **garagenbuch-projekt** als Projektordner auswählen.
4. Als erste Nachricht schreiben:

   > Lies CLAUDE.md und docs/verlauf.md. Mach mir einen Plan, wie wir daraus eine eigene iPhone-App mit Google-Drive-Sicherung bauen. Erklär es einfach.

Claude Code kennt dann alle Entscheidungen aus dem ursprünglichen Chat: MWST, Selbstbehalt-Varianten, Versicherungen, Logo, Bank usw.

Tipp: Die bisherige App im Claude-Chat weiter benutzen, bis die neue fertig ist. Vorher dort unter «Abschluss & Steuern» eine **Komplett-Sicherung** herunterladen – die neue App kann sie einlesen.
